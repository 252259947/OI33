# 隔离 Hydro 集成验证

`hydro-smoke.cjs` 使用真实 Hydro、真实 MongoDB 和真实 HTTP 路由验证新实名与教学模块，不依赖模型 mock。无需修改或部署正在运行的 OJ。

## 安全边界

- 启动前检查 `127.0.0.1:27019` 与 `127.0.0.1:8899` 未被占用；占用时直接退出，不结束已有进程。
- 只创建随机名称的 `/tmp/oi33-hydro-qa-*` 数据库目录、文件目录和临时目录。
- 创建新的 `~/.hydro/profiles/oi33-qa-*`，只读取脚本生成的独立连接配置；不读取或修改原有 Hydro 配置，不改 `HOME`。
- MongoDB 只绑定 `127.0.0.1:27019`，Hydro 只绑定 `127.0.0.1:8899`；不连接 `27017`，不请求 `8888` 或生产站点。
- 强制 `NODE_APP_INSTANCE=qa-fixture`，避免触发主实例对 `~/.hydro/static` 的清理。文件存储与 `TMPDIR` 都指向本次独立目录。
- 插件夹具载入实名、教学、作业访问、最近学习、姓名选择、个人文件权限、批量账号、首页、首页运势、主题、文章与手机访问模块；仅使用合成管理员、教练、学生、题目、训练计划、文章和比赛。不加载 AI 审核/外部服务。
- 非主实例不会建立 Hydro 的核心索引。脚本仅在本次随机数据库补建原生 `document` / `document.status` 唯一索引及讨论列表的 `discussionSort` 索引，保留真实并发认领约束和原生查询提示。
- 结束时只停止脚本自己启动的两个进程。失败也执行清理；不删除原服务、原数据或其他进程。
- 报告比较运行前后 `8888` / `27017` 的监听进程身份，并检查 `8899` / `27019` 已释放；仅查看系统监听表，不访问原服务或原数据库。
- 测试数据和独立 profile 不主动删除，便于复查；`/tmp` 可能被操作系统清理。报告始终写到本目录的 `reports/`，已忽略入 Git。
- 报告不保存初始密码；脚本内固定密码只属于每次新建的隔离夹具，不能用于任何真实账号。
- 清理前检查夹具服务日志，确认不含本次密码、订阅凭据或被 Hydro 捕获并输出的原始 `MessageEvent`；报告只保留检查结果，不复制这些日志。

## 运行

在装有 Hydro 的 Linux / WSL 环境中，使用运行时的 Node.js：

```sh
NODE_PATH=/usr/local/share/.config/yarn/global/node_modules \
  /root/.nix-profile/bin/node tests/live/hydro-smoke.cjs
```

可通过 `OI33_QA_NODE`、`OI33_QA_MONGOD`、`OI33_QA_GLOBAL_MODULES` 指定其他已安装的运行时位置。脚本不安装软件、不改全局依赖。

## 验证覆盖

- 实际登录及实名申请、审核、持久化状态。
- 首页配置显式开启 `checkin: true`，实际载入运势 partial；旧实名学生可抽取，新申请审批前显示认证提示，审批通过后同一登录会话立即显示抽取按钮。不执行签到写操作。
- 个人文件页实际 HTML 中学生上传按钮不可点击且提示“没有权限”，教练/管理员保留原生触发器。真实 `/file` 上传操作拒绝学生和伪造其他域的教练身份；教学身份不提升原生上传权限。测试只提交文件名而不携带文件：教师通过权限关卡后仍由原生 `ValidationError(file)` 拒绝，个人文件列表和存储记录保持不变。
- 新增页面的真实 HTML 模板渲染及 `Cache-Control: private, no-store`。
- 完整载入本仓库模板覆盖（首页 `main.html`、布局、共享组件及各个 partial），真实请求匿名/已核验空首页、匹配班型有作业首页、班外空首页；检查实际返回 200、作业板块只出现一次及正确空态/内容。
- 首页夹具保留旧配置 `hitokoto: true`，上述四种场景均检查“一言”标题与取句容器不再渲染；原生取句脚本零请求及正向对照由 `homepage-hitokoto.test.cjs` 的真实 Chrome 测试覆盖。
- Hydro 对异站 Referer 的 POST 拒绝；原生多选框的重复班型字段正确转换。
- 教练维护班型并通过 Hydro 原作业路由创建作业，普通学生无法创建。
- 新建作业真实 HTML 的默认时间：使用 UTC+14 / UTC−10 两个合成账号核对各自时区的当天 `00:00`，默认截止为 `2100-01-01 00:00`；编辑原有作业保留原起止时间。
- 创建页不显示延期、扣分规则和语言限制控件，题目不再必填；真实提交空字符串或省略介绍/题目均可创建，MongoDB 实际保存 `content: ''`、`pids: []`。
- 请求即使夹带延期、扣分和语言限制参数，保存后仍无延期/扣分/作业语言限制，`endAt` 与 `penaltySince` 完全相等；默认截止的 UTC 存储也按账号时区核对。
- 空作业详情不显示介绍区，显示待补题提示；补加介绍和题目后正常渲染，再编辑清空不会覆盖已发布应交名单，零题目不会使全员被误计为完成。
- 简化表单仍要求标题和班型，学生不能访问编辑页或绕过创建/编辑权限；被拒请求不留下作业或名单变更。
- 真实作业列表使用整卡链接，每项标题和元信息均位于同一卡片内，不嵌套其他链接/按钮。
- `learning-ux-checks.cjs` 在同一隔离夹具中补测个人通过题数、未完成/已完成筛选与排序、零题目状态、长期开放提示、教师保持全作业视图；查询不能冒用其他 UID，列表查询不改变成绩和应交名单。分值由隔离数据库设置合成状态，不启动评测机。
- 首页“继续练习”通过实际原生详情成功后的 finish 钩子记录最近作业或训练计划，覆盖首次回落、训练 PJAX 请求、新登录会话共享记录、非学习详情不记录、参数跨域拒绝、目标删除和转出班型回退；新集合仅保存每域每账号一条导航偏好。
- 真实姓名选择器覆盖学生/匿名访问拒绝、跨域借用教练角色拒绝、实名及用户名搜索、老师管理员排除、字面查询及长度限制、作业管理权限、补发与免除名单范围；选择所得 UID 仍走原有预览与确认路由，不新增绕过确认的写入口。
- 已创建作业的学生/教练详情页真实 HTML 渲染，覆盖共享侧栏；内置作业赛制始终公开成绩榜，不伪造不存在的生产状态来触发隐藏成绩榜分支，该分支由模板单测覆盖。
- 多班型并集去重快照、班外学生拒绝访问、未开始学生统计、班型变化不静默修改历史名单。
- 当前班型同时约束列表、筛选、直链和提交；即使学生留有旧的“查看所有作业/比赛”权限也不能越过班型。教师无须加入学生班型，可预览题目及题面附件，但不会计入学生人数，也不因此获得编辑别人作业或读取测试数据的权限。
- 学生不先进入作业/不手动领取也能直接查看题目或提交。隔离数据库验证实际认领状态、开始时间和评测记录的作业/题目绑定；重复访问不重复计数，转出后旧认领不能绕过权限，转入不静默改应交快照，未来/结束时间限制保留。
- 伪造其他班型筛选、空班型旧作业、无关题目、查询与表单作业编号冲突均被拒绝；给比赛列表附上作业编号不能借用教练预览权限查看隐藏比赛。
- 真实文章广场与“我的文章”模板调用实际摘要 hook，公式只保留单份 TeX；原始 Markdown 不被摘要渲染改写。
- 真实手机访问中间件拒绝手机 GET/POST，保持隐私缓存头与按设备区分的 `Vary` 响应头。
- 临时批量账号预览不建号、确认后创建、指定比赛范围、禁止 unrestricted 题库访问、已登录会话到期即时生效。
- 真实匿名 `/websocket` 连接携带登录凭据订阅消息：正常已核验用户保留订阅能力，临时账号和停用账号被拒绝；测试不发送任何站内消息。

此测试只向随机隔离数据库写入合成提交记录，不启用评测机、不证明真实程序评测可用；也不替代对完整 OI33 插件组合、升级迁移、生产权限配置、已订阅连接的出站事件拦截及其他 WebSocket 行为的验证。

## 比赛复制与结束时间

`contest-editor.cjs` 是较小的独立测试，沿用上述端口隔离规则，创建独立随机 profile 和合成数据。运行方式：

```sh
NODE_PATH=/usr/local/share/.config/yarn/global/node_modules \
  /root/.nix-profile/bin/node tests/live/contest-editor.cjs
```

验证复制 GET 不写库、创建与源比赛编辑权限、域/作业/编号注入拒绝、复制后的新编号及主持人、权限和题目分值配置、并发复制隔离、原参赛状态及记录不变，以及可编辑结束时间的实际保存、无效时间拒绝、旧时长接口与原生作业兼容。附件不复制，复制表单提示重新上传并检查内容引用。不会撤销选手主动提前结束，也不修改 OC 既有的历史 `late` 标记机制。

## 实名姓名自动审核

`enrollment-name-review.cjs` 使用真实实名 handler、模型和 MongoDB；仅 DeepSeek HTTP 响应由 `127.0.0.1:18999` 的本地服务模拟，不读取生产 Provider 或向外部 AI 发送资料。沿用随机 profile、隔离存储、`8899/27019` 端口和进程身份保护，并额外检查模拟 AI 端口未占用、结束后已释放。

```sh
NODE_PATH=/usr/local/share/.config/yarn/global/node_modules \
  /root/.nix-profile/bin/node tests/live/enrollment-name-review.cjs
```

覆盖正常姓名自动通过及旧实名标记同步、同会话状态更新、不授予角色或班型、无需个人 AI 额度、仅发送姓名、格式异常/需人工/畸形回复/上游失败回到待审、开关关闭及模型未登记安全回退、系统费用记录、私有页面缓存和密钥保密。通过暂停模拟 AI 响应，实际并发调用管理员审核/停用和学生重提路由，确认晚到结果不会覆盖人工决策、停用状态或新版本姓名。历史待审、已批量审批和临时比赛账号不因登录/浏览而触发审核；测试不会扫历史账号或操作生产资料。

管理页学生姓名使用原生 `user_detail` 路由和对应 UID 生成个人主页链接；测试实际渲染链接并跟随访问合成学生主页，姓名不写入目标 URL，保留旁边 UID 及管理员访问限制。

此测试证明审批流程与传输边界，不证明真实 DeepSeek 服务可用或姓名归属真实；真实服务验证应单独使用合成姓名，并与完整插件发布验收区分。

### 密码重置与强制改密

同一 `enrollment-name-review.cjs` 还覆盖管理员原生 sudo、非站点管理员及异站请求拒绝、重置后旧密码与会话/API/OAuth 凭据失效、`123456` 登录后直接显示改密表单、改密前业务页面和其他安全操作被拒、原密码错误及重复默认密码不能解锁、成功改密后重新登录、旧版本重置请求不能覆盖新密码。验证实名、班型、角色、权限与历史资料不受影响，并检查操作日志没有密码字段。所有密码写入仅发生在本次随机隔离数据库的合成账号中，不对线上真实学生执行重置。

- 管理员先完成原生 sudo，再逐项发送异站 Origin + 缺失/空 Referer、来源头全缺失、`Origin: null`、畸形来源头、Origin/Referer 冲突、同主机不同协议/端口，以及显式 `Sec-Fetch-Site: cross-site`。每次拒绝后都比较密码 hash/salt、完整实名档案、原生会话及 API/OAuth 凭据，确认没有落库变化。强制改密与普通学生原生改密路径执行相同矩阵。
- 同源 Origin + 无 Referer 的管理员重置、同源 Referer + 无 Origin 的管理员重置/学生改密均验证实际成功，不以“重定向到授权页”代替成功写入。
- 用真实登录 Cookie 建立核心 `/record-detail-conn`，用真实会话凭据建立匿名 `/websocket` 消息订阅。连接在重置前已收到初始数据，重置和强制改密期间不发业务事件，直到学生完成改密恢复正常身份才触发合成评测更新和内存消息事件。旧连接必须以 `4003` 关闭、不得收到新数据；新登录的核心评测连接与消息订阅必须继续正常接收更新。
- 只在隔离夹具中创建一条合成记录（不创建评测任务），测试专用事件路由也仅存在于随机 addon 中且要求站点管理员。消息事件不写入真实或夹具的站内信记录。连接结束后仅关闭本脚本创建的 WebSocket，并检查日志没有会话凭据或原始 `MessageEvent`。
