# 隔离 Hydro 集成验证

`hydro-smoke.cjs` 使用真实 Hydro、真实 MongoDB 和真实 HTTP 路由验证新实名与教学模块，不依赖模型 mock。无需修改或部署正在运行的 OJ。

## 安全边界

- 启动前检查 `127.0.0.1:27019` 与 `127.0.0.1:8899` 未被占用；占用时直接退出，不结束已有进程。
- 只创建随机名称的 `/tmp/oi33-hydro-qa-*` 数据库目录、文件目录和临时目录。
- 创建新的 `~/.hydro/profiles/oi33-qa-*`，只读取脚本生成的独立连接配置；不读取或修改原有 Hydro 配置，不改 `HOME`。
- MongoDB 只绑定 `127.0.0.1:27019`，Hydro 只绑定 `127.0.0.1:8899`；不连接 `27017`，不请求 `8888` 或生产站点。
- 强制 `NODE_APP_INSTANCE=qa-fixture`，避免触发主实例对 `~/.hydro/static` 的清理。文件存储与 `TMPDIR` 都指向本次独立目录。
- 插件夹具载入实名、教学、作业访问、批量账号、首页、主题、文章与手机访问模块；仅使用合成管理员、教练、学生、题目、文章和比赛。不加载 AI 审核/外部服务。
- 非主实例不会建立 Hydro 的核心索引。脚本仅在本次随机数据库补建原生 `document` / `document.status` 唯一索引及讨论列表的 `discussionSort` 索引，保留真实并发认领约束和原生查询提示。
- 结束时只停止脚本自己启动的两个进程。失败也执行清理；不删除原服务、原数据或其他进程。
- 报告比较运行前后 `8888` / `27017` 的监听进程身份，并检查 `8899` / `27019` 已释放；仅查看系统监听表，不访问原服务或原数据库。
- 测试数据和独立 profile 不主动删除，便于复查；`/tmp` 可能被操作系统清理。报告始终写到本目录的 `reports/`，已忽略入 Git。
- 报告不保存初始密码；脚本内固定密码只属于每次新建的隔离夹具，不能用于任何真实账号。
- 清理前检查夹具服务日志，确认不含本次密码、订阅凭据或被 Hydro 捕获并输出的原始 `MessageEvent`；报告只保留检查结果，不复制这些日志。

## 运行

在装有 Hydro 的 Linux / WSL 环境中，使用运行时的 Node.js：

```sh
NODE_PATH=/usr/local/share/.config/yarn/global/node_modules \
  /root/.nix-profile/bin/node tests/live/hydro-smoke.cjs
```

可通过 `OI33_QA_NODE`、`OI33_QA_MONGOD`、`OI33_QA_GLOBAL_MODULES` 指定其他已安装的运行时位置。脚本不安装软件、不改全局依赖。

## 验证覆盖

- 实际登录及实名申请、审核、持久化状态。
- 新增页面的真实 HTML 模板渲染及 `Cache-Control: private, no-store`。
- 完整载入本仓库模板覆盖（首页 `main.html`、布局、共享组件及各个 partial），真实请求匿名/已核验空首页、匹配班型有作业首页、班外空首页；检查实际返回 200、作业板块只出现一次及正确空态/内容。
- Hydro 对异站 Referer 的 POST 拒绝；原生多选框的重复班型字段正确转换。
- 教练维护班型并通过 Hydro 原作业路由创建作业，普通学生无法创建。
- 新建作业真实 HTML 的默认时间：使用 UTC+14 / UTC−10 两个合成账号核对各自时区的当天 `00:00`，默认截止为 `2100-01-01 00:00`；编辑原有作业保留原起止时间。
- 创建页不显示延期、扣分规则和语言限制控件，题目不再必填；真实提交空字符串或省略介绍/题目均可创建，MongoDB 实际保存 `content: ''`、`pids: []`。
- 请求即使夹带延期、扣分和语言限制参数，保存后仍无延期/扣分/作业语言限制，`endAt` 与 `penaltySince` 完全相等；默认截止的 UTC 存储也按账号时区核对。
- 空作业详情不显示介绍区，显示待补题提示；补加介绍和题目后正常渲染，再编辑清空不会覆盖已发布应交名单，零题目不会使全员被误计为完成。
- 简化表单仍要求标题和班型，学生不能访问编辑页或绕过创建/编辑权限；被拒请求不留下作业或名单变更。
- 真实作业列表使用整卡链接，每项标题和元信息均位于同一卡片内，不嵌套其他链接/按钮。
- 已创建作业的学生/教练详情页真实 HTML 渲染，覆盖共享侧栏；内置作业赛制始终公开成绩榜，不伪造不存在的生产状态来触发隐藏成绩榜分支，该分支由模板单测覆盖。
- 多班型并集去重快照、班外学生拒绝访问、未开始学生统计、班型变化不静默修改历史名单。
- 当前班型同时约束列表、筛选、直链和提交；即使学生留有旧的“查看所有作业/比赛”权限也不能越过班型。教师无须加入学生班型，可预览题目及题面附件，但不会计入学生人数，也不因此获得编辑别人作业或读取测试数据的权限。
- 学生不先进入作业/不手动领取也能直接查看题目或提交。隔离数据库验证实际认领状态、开始时间和评测记录的作业/题目绑定；重复访问不重复计数，转出后旧认领不能绕过权限，转入不静默改应交快照，未来/结束时间限制保留。
- 伪造其他班型筛选、空班型旧作业、无关题目、查询与表单作业编号冲突均被拒绝；给比赛列表附上作业编号不能借用教练预览权限查看隐藏比赛。
- 真实文章广场与“我的文章”模板调用实际摘要 hook，公式只保留单份 TeX；原始 Markdown 不被摘要渲染改写。
- 真实手机访问中间件拒绝手机 GET/POST，保持隐私缓存头与按设备区分的 `Vary` 响应头。
- 临时批量账号预览不建号、确认后创建、指定比赛范围、禁止 unrestricted 题库访问、已登录会话到期即时生效。
- 真实匿名 `/websocket` 连接携带登录凭据订阅消息：正常已核验用户保留订阅能力，临时账号和停用账号被拒绝；测试不发送任何站内消息。

此测试只向随机隔离数据库写入合成提交记录，不启用评测机、不证明真实程序评测可用；也不替代对完整 OI33 插件组合、升级迁移、生产权限配置、已订阅连接的出站事件拦截及其他 WebSocket 行为的验证。
